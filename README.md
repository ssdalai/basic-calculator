# Basic Calculator

A small, static calculator website built with HTML, CSS, and JavaScript. It supports the usual arithmetic operations, keyboard input, and a light/dark theme toggle.

## Features

- Addition, subtraction, multiplication, and division
- Percent, decimal, clear, and backspace
- Keyboard shortcuts (numbers, `+ - * /`, Enter, Backspace, Escape)
- Light and dark modes, with the last choice saved in the browser
- Responsive layout that works on phones and desktops

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server:

```bash
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

## GitHub Pages

This project is ready to publish as a GitHub Pages site from the `main` branch root.

1. Open the repository on GitHub
2. Go to **Settings → Pages**
3. Under **Build and deployment**, set Source to **Deploy from a branch**
4. Choose `main` and `/ (root)`, then save

The live URL will look like `https://<your-username>.github.io/basic-calculator/`.
